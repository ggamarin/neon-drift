# Neon Drift — демо-прототип

Играбельный срез по дизайн-документу: один район («Доки»), одна ночь, 7 переездов до КПП с боссом.
Сделан на чистом JS + canvas, без движка и внешних ассетов: его задача — проверить механики, а не быть основой релиза.

## Что внутри

- Карта района с ветвлением и обзором на шаг вперёд, три режима езды.
- Управляемая дорога: три полосы, препятствия и подбираемое; машина едет сама, игрок перестраивается.
- Пошаговый бой прямо в пути: засада нагоняет посреди перегона, после боя поездка продолжается.
- В бою: 3 дистанции, намерения врагов, манёвр, 6 типов врагов, босс.
- Одноразовые обучающие подсказки, которые появляются в момент первой необходимости.
- 6 попутчиков с навыками и минусами, доверие.
- Багажник-сетка 6×4 и бардачок на 3 слота, 12 предметов, 4 апгрейда.
- 8 мирных событий, стоянка, мастерская, критические состояния ресурсов.
- Пиксель-арт 640×360, палитра 32 цвета, свой растровый шрифт с кириллицей, параллакс.
- Цвет как язык: циановый контур — своё, маджента — угроза, янтарь — ресурсы.

Чего нет: сохранений, музыки (только короткие звуки), остальных районов, историй попутчиков и концовок, кроме «прошёл КПП».

## Две версии

| | JS-прототип | Демо на Godot |
| --- | --- | --- |
| Где лежит | `index.html`, `src/` | `godot/` |
| Играть онлайн | https://ggamarin.github.io/neon-drift/ | https://ggamarin.github.io/neon-drift/godot-web/ |
| Графика | Пиксель-арт 640×360 | Векторная 1280×720: сглаживание, градиенты, свечение, дождь частицами |
| Звук | Короткие сигналы | Эффекты, мотор, дождь и музыка — всё синтезом в коде |
| Логика | `src/model.js` | `godot/scripts/model.gd` — порт один в один |

Контент общий: `godot/scripts/data.gd` генерируется из `src/data.js`, поэтому тексты и числа правятся в одном месте.

## Демо на Godot

Нужен Godot 4.7 или новее. В редакторе: «Импорт» → выбрать `godot/project.godot` → F5.

Из командной строки, из папки `godot`:

```bash
godot --path .
```

Проверка, что порт логики точный. Эталонные заезды записаны JS-моделью: сид, лог действий и состояние после каждого шага.
GDScript-модель обязана принять каждое действие и прийти в то же состояние:

```bash
godot --headless --script res://tools/replay.gd
```

Те же заезды через настоящий интерфейс, с отрисовкой каждого шага:

```bash
godot --path . -- --replay
```

Обход ключевых экранов со скриншотами:

```bash
godot --path . -- --tour=/tmp/neon-drift-shots
```

После правки `src/data.js` или логики — перегенерировать данные и эталонные заезды (из корня репозитория):

```bash
node tools/gen-godot.js
```

Веб-сборка лежит в `godot-web/` и собирается пресетом «Web» (нужны шаблоны экспорта Godot):

```bash
godot --headless --path godot --export-release "Web" ../godot-web/index.html
```

Сборка под Windows — один файл `build/NeonDrift.exe` со вшитым игровым пакетом (папка `build/` в репозиторий не входит):

```bash
godot --headless --path godot --export-release "Windows Desktop" ../build/NeonDrift.exe
```

Звук синтезируется кодом при запуске (`godot/scripts/audio.gd`), звуковых файлов в проекте нет: эффекты, гул мотора,
шум дождя и музыкальная петля; ударные вступают в бою. Выключается кнопкой «Звук» на стартовом экране.
Выгрузить всё синтезированное в WAV для проверки:

```bash
godot --path . -- --audio-dump=/tmp/neon-drift-audio
```

Ограничение демо: интерфейс рисуется кодом из `godot/main.gd`, а не собран сценами в редакторе.

## Запуск JS-прототипа

 Открыть `index.html` в браузере. Страница подключает скрипты из `src/` как есть.

Онлайн-версия: https://ggamarin.github.io/neon-drift/

Чтобы получить игру одним файлом (в таком виде она публикуется как артефакт Claude), нужен Node.js 20+:

```bash
node build.js
```

Результат — `dist/index.html`: все скрипты склеены в один, обёртки `<html>` нет.


В консоли браузера доступен `window.__nd`: `state`, `go(action)`, `debug.battle(['boss', 'drone'], true)`.
`__nd.ui.auto = false` останавливает самоход на дороге, `__nd.ui.hintsOff = true` убирает подсказки.
