# Neon Drift — демо-прототип

Играбельный срез по дизайн-документу: один район («Доки»), одна ночь, 7 переездов до КПП с боссом.
Сделан на чистом JS + canvas, без движка и внешних ассетов: его задача — проверить механики, а не быть основой релиза.

## Что внутри

- Карта района с ветвлением и обзором на шаг вперёд, три режима езды.
- Пошаговый бой: 3 дистанции, намерения врагов, манёвр, 6 типов врагов, босс.
- 6 попутчиков с навыками и минусами, доверие.
- Багажник-сетка 6×4 и бардачок на 3 слота, 12 предметов, 4 апгрейда.
- 8 мирных событий, стоянка, мастерская, критические состояния ресурсов.
- Пиксель-арт 640×360, палитра 32 цвета, свой растровый шрифт с кириллицей, параллакс.

Чего нет: сохранений, музыки (только короткие звуки), остальных районов, историй попутчиков и концовок, кроме «прошёл КПП».

## Запуск

Нужен только Node.js 20+; зависимостей нет.

```bash
node build.js
```

Собирает два файла:

- `dist/neon-drift.html` — самодостаточная страница. Её достаточно открыть в браузере.
- `dist/index.html` — тот же код без обёртки `<html>`, в таком виде страница публикуется как артефакт Claude.

## Тесты

```bash
node --test test/sim.test.js
```

Логика (`src/model.js`) не знает про DOM и гоняется в Node: детерминизм по сиду, инварианты после каждого действия,
400 заездов случайного бота, отказ недопустимых действий без изменения состояния, грубая оценка баланса жадным ботом.

```bash
node tools/uirun.js 6
```

Боты играют заезды в настоящем браузере: состояние страницы сверяется с моделью в Node, отрисовка не должна падать.
Скриптам из `tools/` нужен Playwright:

```bash
npm install --no-save playwright
```

```bash
npx playwright install chromium
```

```bash
node tools/shots.js shots
```

Дымовой прогон с настоящими кликами и скриншотами ключевых экранов.

## Устройство

| Файл | Роль |
| --- | --- |
| `src/rng.js` | Детерминированный ГСЧ, состояние лежит в состоянии игры |
| `src/data.js` | Контент: предметы, попутчики, враги, события, режимы езды |
| `src/model.js` | Вся логика. Единственный вход — `act(state, action)` |
| `src/font.js` | Растровый шрифт 5×7 с кириллицей |
| `src/art.js` | Палитра, слои города, спрайты, портреты, значки |
| `src/ui.js` | Экраны и ввод; каждый кадр рисуется из состояния |

Заезд воспроизводится по сиду: открой страницу с `#s424242` в адресе или посмотри сид на стартовом экране.
В консоли браузера доступен `window.__nd`: `state`, `go(action)`, `debug.battle(['boss', 'drone'], true)`.
